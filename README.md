# AI CORNER

**Two Minds. Infinite Possibilities.**

AI CORNER is an interactive learning website that explores one question: *How can human intelligence and artificial intelligence work together to solve problems and create new possibilities?*

It is built as a college innovation project. It runs entirely in the browser as a single HTML file, with no login and no server.

## Features

- **Human vs AI Arena:** a six-question quiz on creativity, reasoning, pattern recognition, decision-making, emotional understanding and responsible AI use. It shows that results depend on the task and context.
- **Human + AI Challenge Lab:** six real problems (food waste, accessible education, water conservation, sustainable agriculture, environmental protection, everyday productivity). Each shows the problem, human insight, AI assistance, a combined solution, and benefits, limits and responsible use.
- **Idea Fusion Lab:** enter an idea and a category to get Human Insight, AI Contribution and Combined Innovation sections, with a copy button. It uses built-in sample templates and is clearly labelled as not coming from a real AI model.
- **Daily Brain Boost:** riddles, logic puzzles and a creative exercise, with hints, explanations and XP.
- **Explore AI Universe:** eight beginner-friendly cards, each with a real-world example.
- **Comparison Dashboard:** human and AI strengths side by side. Bars are illustrative, not measured data.
- **AI Corner Assistant:** a floating demo chatbot with ready-made answers. It is not a live AI.
- **XP, levels and badges:** Explorer, Thinker, Innovator and AI Collaborator, with a Reset Progress button.

## Privacy

- Guest mode only: no login, sign-up, passwords or personal information.
- Progress is saved in the browser's `localStorage` on the user's own device.
- No data is sent to any server. There are no analytics, trackers, cookies or third-party scripts.

## Accessibility

Responsive layout for mobile, tablet and desktop, keyboard navigation with visible focus, a skip link, labelled controls and support for reduced-motion settings.

## Run it

1. Download `index.html`.
2. Open it in any modern browser. No install or build step is needed.

## Deploy on GitHub Pages

1. Upload `index.html` to a public repository.
2. Go to **Settings**, then **Pages**.
3. Choose branch **main** and folder **/ (root)**, then save.
4. Open `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Tech

Plain HTML, CSS and JavaScript in one file. No frameworks or libraries.

## Notes and limits

- Quiz, puzzle and chat content is pre-written and limited in size.
- Idea Fusion and the Assistant use fixed templates and keyword replies, not a live AI.
- Comparison scores are illustrative only.
